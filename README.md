# 🚀 Next.js + Tailwind CSS Demo

A minimal, modern web demo built with **Next.js 15** and **Tailwind CSS 3**, designed to show best practices for SEO-friendly, high-performance React apps.

---

## 🌟 Features

- ⚡ **Next.js 15 (App Router)** — file-based routing, metadata API, and static site generation.
- 🎨 **Tailwind CSS 3** — utility-first styling with dark mode and responsive layouts.
- 🔍 **SEO Ready** — optimized `<head>` metadata, sitemap, and open graph tags.
- 📱 **Responsive Design** — mobile-first layout and reusable components.
- 🧱 **Components Example** — Navbar, Hero, Footer, and Cards for quick reuse.
- 🌍 **Deployment Ready** — easily deploy on Vercel or Netlify.

---

## 🛠️ Tech Stack

| Tech | Description |
|------|--------------|
| [Next.js](https://nextjs.org/) | React framework for SSR/SSG |
| [Tailwind CSS](https://tailwindcss.com/) | Utility-first CSS framework |
| [TypeScript](https://www.typescriptlang.org/) | Type-safe React development |
| [Vercel](https://vercel.com/) | Deployment and hosting |
